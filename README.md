# ✨ Hardware-Accelerated Ray Tracing with Metal Shader Language (MSL)

 This project implements **hardware-accelerated ray tracing** using
**Apple's Metal API** and **Metal Shader Language (MSL)**.\
 The implementation is inspired by the popular tutorial *Ray Tracing in
One Weekend* by Peter Shirley, Trevor David Black, and Steve Hollasch.


------------------------------------------------------------------------

## 🚀 How to Build & Run

``` bash
make clean        # Clean any previous build artifacts
make              # Compile the project (main.mm)
./MyMetalProject  # Run the executable
```

------------------------------------------------------------------------

## 🖥️ Project Overview

-   **Purpose**: Demonstrates GPU-accelerated ray tracing using MSL and
    Metal compute shaders.
-   **Core Features**:
    -   ⚡ Uses Metal's compute pipeline for efficient ray tracing.
    -   🔮 Implements fundamentals from *Ray Tracing in One Weekend*
        (camera, spheres, shading).

------------------------------------------------------------------------

## ⚙️ Requirements

-   🍎 macOS with **Metal** support
-   🛠️ Xcode command-line tools (for `make` & compilation)
